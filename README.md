# E-Commerce Analytics Dashboard

## Project Overview

This project analyzes e-commerce transactions from the Olist marketplace dataset using SQLite, SQL, and Power BI.

The objective was to identify business trends, understand customer behavior, evaluate product performance, assess customer satisfaction, and analyze logistics performance through an interactive dashboard.

## Tools Used

- SQLite
- SQL
- Power BI
- GitHub

## Dataset

Source: Olist Brazilian E-Commerce Dataset

Dataset Size:

- 99,441 Orders
- 99,441 Customers
- 32,951 Products
- 3,095 Sellers
- 99,224 Reviews

## Data Quality Checks

Performed validation checks to ensure data integrity:

- No duplicate order IDs
- No missing customer IDs
- No missing product IDs
- No missing seller IDs

## Key Findings

### Sales Performance

- Revenue exceeded 16 million.
- Revenue grew consistently throughout 2017 and early 2018.
- Peak monthly revenue exceeded 1.1 million.

### Customer Analysis

- São Paulo was the largest customer market with over 41,000 customers.
- Customer activity was concentrated in southeastern Brazil.

### Product Analysis

Top revenue-generating categories:

1. Home & Living (cama_mesa_banho)
2. Beauty & Health (beleza_saude)
3. Technology Accessories (informatica_acessorios)

### Customer Satisfaction

- More than 77% of reviews received 4 or 5 stars.
- Over 57,000 reviews received a 5-star rating.

### Logistics

- Average delivery time was 12.56 days.
- Delivery performance had a measurable impact on customer satisfaction.
